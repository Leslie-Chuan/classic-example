## 今日主题

理解 **React Server Components（RSC）** 如何与 **AI 流式输出** 结合，打造“零客户端包体积、渐进式渲染”的 AI 交互体验。

关键词：RSC、Streaming SSR、Suspense、流式 UI、Vercel AI SDK

---

## 核心概念

### 1. React Server Components（RSC）的本质

RSC 是在服务端渲染的 React 组件，**不会打包到客户端**。它可以直接访问数据库、文件系统或 AI API，然后把渲染结果（React 节点树）以流式格式发送给浏览器。

```text
传统 SSR：Server → HTML → Client → hydrate → 交互
RSC    ：Server → React Node Stream → Client 直接展示（无需 hydrate RSC 部分）
```

### 2. 流式 SSR 与 Suspense 边界

React 18 的 `Suspense` 允许组件在异步数据准备好之前先展示 `fallback`，服务端可以把 HTML 分块推送。

```tsx
<Suspense fallback={<Skeleton />}>
  <AIResponse prompt="解释 useTransition" />
</Suspense>
```

浏览器会先看到骨架屏，AI 响应到达后自动替换为真实内容。

### 3. AI 流式输出的 UI 挑战

LLM 返回的是**逐 token 生成的文本**，UI 需要：

- 尽快展示首 token，降低用户等待感；
- 支持流式追加，而不是等全部生成完再渲染；
- 处理加载、错误、中断、重试状态。

RSC + Suspense 天然适合：服务端请求 AI，将生成的内容作为 React 节点流式下发。

### 4. RSC + AI 的三种典型模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| 服务端一次性生成 | RSC 等待 AI 返回完整内容后渲染 | 短回答、对延迟不敏感 |
| 服务端流式生成 + Suspense | 用 `streamText` / `createStreamableUI` 分块推送 | 长文本、代码解释 |
| Client 流式组件（`useChat`） | 浏览器直接建立 SSE 连接 | 交互式聊天、实时反馈 |

## 代码实践

### 实践标题：用 Next.js App Router + Vercel AI SDK 实现“AI 代码解释器”

目标：创建一个 RSC 页面，用户输入组件名，服务端流式返回该组件的代码解释。

#### 步骤 1：安装依赖

```bash
npx create-next-app@latest ai-rsc-demo --app --typescript --tailwind
npm install ai @ai-sdk/openai
```

#### 步骤 2：创建 Server Action（`app/actions.ts`）

```ts
"use server";

import { streamText } from "ai";
import { openai } from "@ai-sdk/openai";
import { createStreamableValue } from "ai/rsc";

export async function explainComponent(name: string) {
  const stream = createStreamableValue("");

  (async () => {
    const { textStream } = streamText({
      model: openai("gpt-4o-mini"),
      prompt: `用中文简要解释 React 组件 ${name} 的作用、常用场景和注意事项。`,
    });

    for await (const delta of textStream) {
      stream.update(delta);
    }

    stream.done();
  })();

  return stream.value;
}
```

#### 步骤 3：创建流式展示组件（`app/Explanation.tsx`）

```tsx
"use client";

import { useStreamableValue } from "ai/rsc";

export function Explanation({
  stream,
}: {
  stream: Awaited<ReturnType<typeof import("./actions").explainComponent>>;
}) {
  const [data, error, pending] = useStreamableValue(stream);

  return (
    <div className="rounded-lg border bg-gray-50 p-4">
      <p className="whitespace-pre-wrap text-sm leading-relaxed">
        {data}
        {pending && <span className="animate-pulse">▌</span>}
      </p>
      {error && <p className="text-red-500 mt-2">出错：{error.message}</p>}
    </div>
  );
}
```

#### 步骤 4：创建 RSC 页面（`app/page.tsx`）

```tsx
import { Suspense } from "react";
import { explainComponent } from "./actions";
import { Explanation } from "./Explanation";

export default async function Page({
  searchParams,
}: {
  searchParams: { name?: string };
}) {
  const name = searchParams.name || "useEffect";
  const stream = await explainComponent(name);

  return (
    <main className="max-w-2xl mx-auto p-8">
      <h1 className="text-2xl font-bold mb-4">AI 组件解释器</h1>
      <p className="text-gray-600 mb-6">今日主题：{name}</p>

      <Suspense fallback={<div className="h-32 bg-gray-100 rounded animate-pulse" />}>
        <Explanation stream={stream} />
      </Suspense>
    </main>
  );
}
```

#### 关键观察

1. `page.tsx` 是 RSC，直接在服务端调用 `explainComponent`；
2. `createStreamableValue` 把 AI token 流包装成可序列化的 React 流；
3. `Explanation` 是 Client Component，负责在浏览器端消费流并展示光标；
4. `Suspense` 让首屏立即渲染，避免白屏等待。
