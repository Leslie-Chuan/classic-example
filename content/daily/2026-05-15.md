## 核心概念（10 分钟）

### 1. 为什么需要 Prompt 库

- **一致性**：团队或个人在不同场景下使用统一的 Prompt 模板，减少重复设计
- **版本控制**：Prompt 也是代码，需要追踪变更、A/B 测试效果、回滚失败版本
- **可组合性**：好的 Prompt 库像组件库一样，可以拼装使用

### 2. Prompt 库的组织结构

推荐的目录结构：

```
prompt-library/
├── code-review/          # 代码审查类
│   ├── frontend-review.md
│   ├── security-check.md
│   └── performance-audit.md
├── code-generation/      # 代码生成类
│   ├── component-scaffold.md
│   ├── api-wrapper.md
│   └── test-generator.md
├── refactoring/          # 重构辅助类
│   ├── identify-smell.md
│   └── migration-guide.md
├── documentation/        # 文档生成类
│   ├── jsdoc-generator.md
│   └── readme-writer.md
└── _templates/           # 通用模板与元数据
    ├── base-system.md
    └── prompt-metadata.schema.json
```

### 3. Prompt 元数据设计

每个 Prompt 文件应包含结构化元数据：

```yaml
---
name: "Frontend Component Review"
version: "1.2.0"
category: "code-review"
description: "审查 React/Vue 组件的代码质量、性能和可访问性"
tags: [react, vue, accessibility, performance]
last_tested: "2026-05-15"
effectiveness_score: 0.85
---
```

### 4. Prompt 质量评估维度

- **准确性**：输出是否符合预期（目标 > 85%）
- **稳定性**：多次运行结果是否一致
- **可控性**：通过参数调整输出的粒度
- **效率**：Token 消耗是否在合理范围

## 代码实践（12 分钟）

### 实践 1：创建一个 Prompt 模板文件

创建一个可参数化的代码审查 Prompt：

```markdown
---
name: "Component Review"
version: "1.0.0"
params:
  - framework: "react"        # react | vue | angular
  - focus: "performance"      # performance | a11y | security | all
---

你是一位资深 {{framework}} 前端工程师。请审查以下组件，重点关注 {{focus}} 方面。

## 审查要求
1. 指出潜在的代码坏味道（命名、职责、复杂度）
2. 分析性能瓶颈并提供优化建议
3. 检查是否符合最佳实践（Hooks 使用、状态管理等）
4. 给出具体的改进代码示例

## 待审查代码
\`\`\`
{{code}}
\`\`\`

## 输出格式
- **问题清单**：按严重程度排序
- **改进建议**：附带修改前后的代码对比
- **评分**：1-10 分，附理由
```

### 实践 2：用脚本管理 Prompt 版本

```javascript
// prompt-manager.js — 简易的 Prompt 库管理工具
const fs = require('fs');
const path = require('path');
const yaml = require('js-yaml');

class PromptLibrary {
  constructor(basePath) {
    this.basePath = basePath;
  }

  loadPrompt(category, name) {
    const filePath = path.join(this.basePath, category, `${name}.md`);
    const content = fs.readFileSync(filePath, 'utf-8');
    const parts = content.split('---');
    if (parts.length >= 3) {
      const meta = yaml.load(parts[1]);
      const body = parts.slice(2).join('---').trim();
      return { meta, body };
    }
    return { meta: null, body: content };
  }

  renderPrompt(category, name, params) {
    const { body } = this.loadPrompt(category, name);
    return body.replace(/\{\{(\w+)\}\}/g, (_, key) => params[key] || `{{${key}}}`);
  }

  listPrompts() {
    const categories = fs.readdirSync(this.basePath)
      .filter(d => fs.statSync(path.join(this.basePath, d)).isDirectory());

    return categories.map(cat => ({
      category: cat,
      prompts: fs.readdirSync(path.join(this.basePath, cat))
        .filter(f => f.endsWith('.md'))
        .map(f => {
          const { meta } = this.loadPrompt(cat, f.replace('.md', ''));
          return { file: f, ...meta };
        })
    }));
  }
}

module.exports = PromptLibrary;
```
