## 核心概念（8分钟）

### 1. Mini Agent的架构蓝图

一个可工作的Coding Agent最少需要哪些组件？

```
┌─────────────────────────────────────────┐
│              User Input                 │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  Agent Loop（感知→思考→行动→观察）      │
│  • 把用户请求注入System Prompt           │
│  • 每次循环向LLM发送完整上下文           │
│  • 解析LLM返回的Tool Call JSON           │
│  • 执行工具并追加结果到上下文            │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  Tool Registry（工具注册表）             │
│  • read_file / write_file               │
│  • execute_command（带白名单限制）       │
│  • list_directory                       │
└─────────────────┬───────────────────────┘
                  ▼
┌─────────────────────────────────────────┐
│  Safety Sandbox（安全沙箱）              │
│  • 限制可访问的目录范围                  │
│  • 命令执行白名单（只读/写入分离）       │
│  • 最大循环次数防止无限执行              │
└─────────────────────────────────────────┘
```

### 2. 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 上下文管理 | 完整历史数组 | 简单可靠，适合Mini Agent；生产环境需用摘要或滑动窗口 |
| Tool定义格式 | OpenAI Function Calling | 生态成熟，Claude也兼容；降低解析复杂度 |
| 沙箱策略 | 目录白名单 + 命令白名单 | 200行内最易实现，防误删根目录 |
| 停止条件 | `finish`工具 + 最大循环数 | 让Agent主动报告完成，避免过度执行 |

### 3. Agent Loop的状态机

```
          ┌─────────────┐
          │    IDLE     │
          └──────┬──────┘
                 │ 收到用户输入
                 ▼
          ┌─────────────┐
          │  CALL_LLM   │
          └──────┬──────┘
                 │ LLM返回
                 ▼
      ┌──────────────────────┐
      │  是否有Tool Call？   │
      └──────┬────────┬──────┘
        是   │        │ 否
             ▼        ▼
   ┌────────────┐  ┌────────────┐
   │  EXECUTE   │  │  RESPONSE  │
   │   TOOL     │  │  TO USER   │
   └──────┬─────┘  └────────────┘
          │
          │ 追加结果到上下文
          └──────────────► CALL_LLM（再次循环）
```

## 代码实践（15分钟）

### MiniAgent.ts — 完整实现

```typescript
import { OpenAI } from 'openai';
import * as fs from 'fs/promises';
import * as path from 'path';
import { execSync } from 'child_process';

interface Tool {
  name: string;
  description: string;
  parameters: object;
  execute: (args: any) => Promise<string>;
}

interface Message {
  role: 'system' | 'user' | 'assistant' | 'tool';
  content: string;
  tool_calls?: any[];
  name?: string;
  tool_call_id?: string;
}

export class MiniAgent {
  private client: OpenAI;
  private messages: Message[] = [];
  private tools: Tool[];
  private maxIterations = 10;
  private allowedDirs: string[];

  constructor(apiKey: string, allowedDirs: string[] = [process.cwd()]) {
    this.client = new OpenAI({ apiKey });
    this.allowedDirs = allowedDirs.map(d => path.resolve(d));
    this.tools = this.buildTools();
    this.messages.push({
      role: 'system',
      content: `你是一个谨慎的编程助手。你只能访问被允许的目录。
可用工具：read_file、write_file、execute_command、list_directory、finish。
执行命令前请三思，优先使用只读操作。完成时请调用finish工具。`
    });
  }

  async run(userInput: string): Promise<string> {
    this.messages.push({ role: 'user', content: userInput });

    for (let i = 0; i < this.maxIterations; i++) {
      const response = await this.client.chat.completions.create({
        model: 'gpt-4o-mini',
        messages: this.messages as any,
        tools: this.tools.map(t => ({
          type: 'function' as const,
          function: {
            name: t.name,
            description: t.description,
            parameters: t.parameters,
          },
        })),
        tool_choice: 'auto',
      });

      const assistantMsg = response.choices[0].message;
      this.messages.push({
        role: 'assistant',
        content: assistantMsg.content || '',
        tool_calls: assistantMsg.tool_calls,
      });

      if (!assistantMsg.tool_calls || assistantMsg.tool_calls.length === 0) {
        return assistantMsg.content || '无回复';
      }

      for (const call of assistantMsg.tool_calls) {
        const result = await this.executeTool(call.function.name, JSON.parse(call.function.arguments));
        this.messages.push({
          role: 'tool',
          content: result,
          tool_call_id: call.id,
          name: call.function.name,
        });

        if (call.function.name === 'finish') {
          return result;
        }
      }
    }
    return '达到最大循环次数，任务未完成。';
  }

  private async executeTool(name: string, args: any): Promise<string> {
    const tool = this.tools.find(t => t.name === name);
    if (!tool) return `错误：未知工具 "${name}"`;
    try {
      return await tool.execute(args);
    } catch (e: any) {
      return `执行错误：${e.message}`;
    }
  }

  private buildTools(): Tool[] {
    return [
      {
        name: 'read_file',
        description: '读取指定文件的内容',
        parameters: {
          type: 'object',
          properties: { file_path: { type: 'string' } },
          required: ['file_path'],
        },
        execute: async ({ file_path }) => {
          const full = path.resolve(file_path);
          this.assertAllowed(full);
          return await fs.readFile(full, 'utf-8');
        },
      },
      {
        name: 'write_file',
        description: '向指定文件写入内容，会覆盖已有内容',
        parameters: {
          type: 'object',
          properties: {
            file_path: { type: 'string' },
            content: { type: 'string' },
          },
          required: ['file_path', 'content'],
        },
        execute: async ({ file_path, content }) => {
          const full = path.resolve(file_path);
          this.assertAllowed(full);
          await fs.mkdir(path.dirname(full), { recursive: true });
          await fs.writeFile(full, content, 'utf-8');
          return `已写入 ${file_path}`;
        },
      },
      {
        name: 'list_directory',
        description: '列出目录下的文件和子目录',
        parameters: {
          type: 'object',
          properties: { dir_path: { type: 'string' } },
          required: ['dir_path'],
        },
        execute: async ({ dir_path }) => {
          const full = path.resolve(dir_path);
          this.assertAllowed(full);
          const entries = await fs.readdir(full, { withFileTypes: true });
          return entries.map(e => (e.isDirectory() ? '[D] ' : '[F] ') + e.name).join('\n');
        },
      },
      {
        name: 'execute_command',
        description: '在允许范围内执行shell命令（仅限git/npm/node/tsc）',
        parameters: {
          type: 'object',
          properties: { command: { type: 'string' } },
          required: ['command'],
        },
        execute: async ({ command }) => {
          const allowedPrefixes = ['git ', 'npm ', 'node ', 'npx ', 'tsc '];
          if (!allowedPrefixes.some(p => command.startsWith(p))) {
            return `拒绝执行："${command}" 不在白名单中。`;
          }
          return execSync(command, { cwd: this.allowedDirs[0], encoding: 'utf-8', timeout: 10000 });
        },
      },
      {
        name: 'finish',
        description: '标记任务已完成，向用户汇报结果',
        parameters: {
          type: 'object',
          properties: { summary: { type: 'string' } },
          required: ['summary'],
        },
        execute: async ({ summary }) => `✅ 任务完成：${summary}`,
      },
    ];
  }

  private assertAllowed(filePath: string) {
    if (!this.allowedDirs.some(dir => filePath.startsWith(dir))) {
      throw new Error(`路径 ${filePath} 不在允许的目录范围内`);
    }
  }
}

// 使用示例
```

## 思考题（5分钟）

1. **上下文爆炸**：如果Agent连续执行20次循环，token消耗会迅速增长。你会如何在不破坏Loop结构的前提下做上下文压缩？
2. **权限粒度**：当前沙箱使用"目录白名单 + 命令前缀白名单"，在生产环境中这种粗粒度控制有哪些风险？如何改进？
3. **错误恢复**：如果`execute_command`返回非零退出码，当前实现只是把错误文本塞回上下文。设计一个更优雅的重试/降级策略。
4. **扩展性**：如果明天要新增一个"搜索网络"工具，代码中哪些地方需要改动？能否做到"注册即生效"的动态工具加载？
