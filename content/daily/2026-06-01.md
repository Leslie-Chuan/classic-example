### 2.2 三个关键设计决策（及其答案）

**Q1：AI助手应该解决什么问题？**
- 不是"能做什么"，而是"用户高频痛点是什么"
- Week 5建议：从"代码审查辅助"或"组件文档问答"入手，有明确输入输出边界

**Q2：为什么RAG比长上下文更可靠？**
- 长上下文 = 全部塞进去，成本高、幻觉多、不可控
- RAG = 先检索再生成，精准、可溯源、成本可控
- 前端场景：组件库文档、API规范、设计系统Token表，都是RAG的优质素材

**Q3：流式UI不是炫技，而是心理模型**
- 用户看到逐字输出，感知到"AI正在思考"
- 配合光标跳动、进度提示，可显著降低等待焦虑
- 错误时优雅降级（非空白的突然停止）比完美输出更重要

## 三、代码实践（15分钟）

### 3.1 实践主题：一个"最小可运行"的 RAG + Streaming 整合Demo

下面的代码把Week 5的核心能力串成一条线：**读取代码文件 → AST提取 → 向量化存储 → 流式问答**。你可以直接复制到本地运行（需要`@babel/parser`和`openai`包）。

```typescript
// mini-ai-assistant.ts
// Week 5 整合Demo：RAG + Streaming + AST

import { parse } from '@babel/parser';
import traverse from '@babel/traverse';
import OpenAI from 'openai';

// ========== 1. AST代码解析（Day 32） ==========
interface CodeChunk {
  type: 'function' | 'class' | 'component';
  name: string;
  code: string;
  lineStart: number;
}

function extractChunks(sourceCode: string): CodeChunk[] {
  const ast = parse(sourceCode, {
    sourceType: 'module',
    plugins: ['jsx', 'typescript'],
  });

  const chunks: CodeChunk[] = [];

  traverse(ast, {
    FunctionDeclaration(path) {
      chunks.push({
        type: 'function',
        name: path.node.id?.name || 'anonymous',
        code: sourceCode.slice(path.node.start!, path.node.end!),
        lineStart: path.node.loc?.start.line || 0,
      });
    },
    ClassDeclaration(path) {
      chunks.push({
        type: 'class',
        name: path.node.id?.name || 'anonymous',
        code: sourceCode.slice(path.node.start!, path.node.end!),
        lineStart: path.node.loc?.start.line || 0,
      });
    },
  });

  return chunks;
}

// ========== 2. 简易向量存储（Day 31 简化版） ==========
class SimpleVectorStore {
  private docs: { text: string; embedding: number[] }[] = [];

  // 简化：用字符编码均值作为"伪embedding"，仅供演示结构
  private fakeEmbedding(text: string): number[] {
    const vec = new Array(64).fill(0);
    for (let i = 0; i < text.length; i++) {
      vec[i % 64] += text.charCodeAt(i) / text.length;
    }
    return vec;
  }

  add(text: string) {
    this.docs.push({ text, embedding: this.fakeEmbedding(text) });
  }

  search(query: string, topK = 3) {
    const q = this.fakeEmbedding(query);
    return this.docs
      .map((d) => ({
        text: d.text,
        score: cosineSimilarity(q, d.embedding),
      }))
      .sort((a, b) => b.score - a.score)
      .slice(0, topK);
  }
}

function cosineSimilarity(a: number[], b: number[]): number {
  let dot = 0, na = 0, nb = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    na += a[i] * a[i];
    nb += b[i] * b[i];
  }
  return dot / (Math.sqrt(na) * Math.sqrt(nb));
}

// ========== 3. 流式问答（Day 33） ==========
const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

async function* askWithRAG(
  question: string,
  store: SimpleVectorStore
) {
  // 检索相关上下文
  const contexts = store.search(question, 2);
  const contextText = contexts.map((c) => c.text).join('\n---\n');

  const systemPrompt = `你是一个资深前端代码助手。请基于以下代码上下文回答问题：\n${contextText}`;

  const stream = await openai.chat.completions.create({
    model: 'gpt-4o-mini',
    messages: [
      { role: 'system', content: systemPrompt },
      { role: 'user', content: question },
    ],
    stream: true,
  });

  for await (const chunk of stream) {
    const content = chunk.choices[0]?.delta?.content || '';
    if (content) yield content;
  }
}

// ========== 4. 运行示例 ==========
async function main() {
  const sampleCode = `
function useDebounce<T extends (...args: any[]) => any>(fn: T, delay: number) {
  let timer: ReturnType<typeof setTimeout>;
  return (...args: Parameters<T>) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

class EventEmitter {
  private listeners = new Map<string, Function[]>();
  on(event: string, cb: Function) {
    if (!this.listeners.has(event)) this.listeners.set(event, []);
    this.listeners.get(event)!.push(cb);
  }
}
`;

  // 解析 → 存入向量库
  const chunks = extractChunks(sampleCode);
  const store = new SimpleVectorStore();
  chunks.forEach((c) => store.add(`${c.type} ${c.name}:\n${c.code}`));

  // 流式提问
  console.log('👤 提问：debounce 的作用是什么？\n🤖 AI回答：');
  for await (const token of askWithRAG('debounce 的作用是什么？', store)) {
    process.stdout.write(token); // 逐字输出，体验流式效果
  }
  console.log('\n✅ Done');
}

main();
```

### 3.2 运行与观察重点

1. **替换fake embedding**：上面的`fakeEmbedding`仅用于演示RAG流程结构，生产环境请替换为`text-embedding-3-small`或开源模型
2. **AST提取的扩展性**：当前只提取了Function和Class，你可以尝试加入`JSXElement`提取组件Props
3. **流式体验**：注意`process.stdout.write(token)`的效果——这就是Day 33说的"心理模型"
4. **错误边界缺失**：上面的代码没有try/catch，请思考：如果OpenAI API超时，UI层应该如何降级？
