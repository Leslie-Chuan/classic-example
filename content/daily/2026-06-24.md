## 【核心概念】5 分钟精读

### 1. 组件库搜索的困境

传统组件库搜索依赖名称、分类和标签。但开发者的真实查询往往是自然语言：

- "需要一个能展示进度、可以手动中断、带错误提示的上传组件"
- "找一个支持键盘导航的多选下拉框"
- "表单校验失败时高亮显示的输入框"

关键词搜索在这种场景下会失效，因为它无法捕捉"上传"与"Upload"、"多选"与"multiple"之间的语义关系。RAG 的核心价值，就是把查询和组件文档映射到同一个向量空间，用语义相似度找到最匹配的组件。

### 2. 组件文档的向量化策略

组件文档不是一篇文章，它由多个结构化字段组成。向量化时需要做两个决策：

**粒度选择**
- 粗粒度：整个组件文档生成一个向量，简单但会丢失细节。
- 细粒度：每个 prop、每个示例、每段描述分别生成向量，召回更精准，但索引量更大。
- 混合粒度：组件级向量用于初步召回，prop 级向量用于精确回答"这个组件有没有某个能力"。

**文本构建方式**
不要把原始 JSON 直接丢给嵌入模型，而是拼接成自然语言。例如：

```text
组件 Button，分类 general。触发一个操作的交互控件，支持主色、次要、危险等变体。
主要属性包括：type: 按钮视觉类型（类型 'primary' | 'secondary' | 'danger'，默认 'primary'）；...
典型使用场景：表单提交、确认删除、加载中请求。标签：interaction、form、action。
```

这样做的好处是：嵌入模型对自然语言的理解远强于对结构化数据的理解。

### 3. 前端 RAG 的简化架构

```
离线阶段：组件源码/Markdown/Storybook → 文档解析 → 文本分块 → 生成 embedding → 写入向量库
在线阶段：自然语言查询 → 生成 embedding → Top-K 相似度检索 → 组装结果上下文 → 返回组件列表
```

对于前端团队，向量库的选择可以是：
- **内存数组**：Demo 阶段，几百个组件以内完全够用。
- **pgvector**：已有 PostgreSQL 的团队，零额外成本。
- **Pinecone/Milvus/Qdrant**：大规模、需要混合搜索和过滤的场景。

### 4. 混合搜索的必要性

纯向量搜索擅长语义匹配，但会漏掉精确的字符匹配。例如用户输入 "Button"，向量搜索可能把 "IconButton"、"SubmitButton" 排在 "Button" 前面。

最简单的混合策略是：

```
最终分数 = 语义相似度 × 0.7 + 关键词匹配分 × 0.3
```

关键词匹配可以基于组件名、props、tags 等字段做简单加权。工业级方案会用 BM25 + 重排序模型（如 Cohere Rerank），但前端原型阶段，加权混合已经能跑得很好。

### 5. 工程落地的三个取舍

- **客户端还是服务端做 embedding？**  本节 Demo 放在服务端，因为 OpenAI API key 不能暴露。浏览器端方案可以考虑 Edge Function、本地小模型（如 all-MiniLM via Transformers.js）或私有化嵌入服务。
- **索引如何增量更新？**  组件库会不断迭代，需要给每个文档块标记 `componentId` + `version`，更新时先删除旧向量再写入新向量。
- **结果如何解释？**  把语义分数和关键词分数都展示给开发者，能帮助他理解"为什么返回这个组件"，也方便后续调优。

```javascript
/**
 * 把组件文档拼接成一段自然语言，供嵌入模型理解。
 * 注意：不要把 JSON 直接传过去，嵌入模型更擅长处理自然语言。
 */
function buildEmbeddingText(doc) {
  const propsText = doc.props
    .map((p) => `${p.name}：${p.desc}（类型 ${p.type}，默认 ${p.default}）`)
    .join('；');
  return `组件 ${doc.name}，分类 ${doc.category}。${doc.description}主要属性包括：${propsText}。典型使用场景：${doc.examples.join('、')}。标签：${doc.tags.join('、')}。`;
}

// ===== 2. 调用 OpenAI Embedding API 生成向量 =====
async function fetchEmbedding(text) {
  const res = await fetch('https://api.openai.com/v1/embeddings', {
    method: 'POST',
    headers: {
      Authorization: `Bearer ${process.env.OPENAI_API_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      model: 'text-embedding-3-small', // 1536 维，性价比高
      input: text,
    }),
  });
  if (!res.ok) {
    throw new Error(`Embedding request failed: ${res.status} ${await res.text()}`);
  }
  const data = await res.json();
  return data.data[0].embedding;
}

// ===== 3. 相似度计算：余弦相似度 + 关键词加权 =====
function cosineSimilarity(a, b) {
  let dot = 0;
  let normA = 0;
  let normB = 0;
  for (let i = 0; i < a.length; i++) {
    dot += a[i] * b[i];
    normA += a[i] * a[i];
    normB += b[i] * b[i];
  }
  return dot / (Math.sqrt(normA) * Math.sqrt(normB));
}

function keywordScore(query, doc) {
  const q = query.toLowerCase();
  let score = 0;
  if (doc.name.toLowerCase().includes(q)) score += 0.3;        // 组件名命中权重最高
  if (doc.description.toLowerCase().includes(q)) score += 0.15;
  if (doc.tags.some((t) => t.toLowerCase().includes(q))) score += 0.2;
  if (doc.props.some((p) => p.name.toLowerCase().includes(q))) score += 0.15;
  if (doc.examples.some((e) => e.toLowerCase().includes(q))) score += 0.1;
  return score;
}

// ===== 4. 构建向量索引（启动时一次性构建，实际项目可持久化到向量库）=====
let index = null;

async function buildIndex() {
  console.log('正在构建组件向量索引...');
  const docs = [];
  for (const doc of componentDocs) {
    const text = buildEmbeddingText(doc);
    const vector = await fetchEmbedding(text);
    docs.push({ ...doc, vector });
  }
  index = docs;
  console.log(`索引构建完成：${docs.length} 个组件`);
}

// ===== 5. 搜索：语义 + 关键词混合排序 =====
async function search(query, topK = 5) {
  if (!index) throw new Error('索引尚未构建完成');
  const qVector = await fetchEmbedding(query);
  const results = index.map((doc) => {
    const semantic = cosineSimilarity(qVector, doc.vector);
    const keyword = keywordScore(query, doc);
    const score = semantic * 0.7 + keyword * 0.3; // 可调整的混合权重
    return { ...doc, score, semantic, keyword };
  });
  return results.sort((a, b) => b.score - a.score).slice(0, topK);
}

// ===== 6. 启动 HTTP 服务 =====
const PORT = 3456;

function serveStatic(res, filePath, contentType) {
  fs.readFile(filePath, (err, data) => {
    if (err) {
      res.writeHead(404);
      res.end('Not found');
    } else {
      res.writeHead(200, { 'Content-Type': contentType });
      res.end(data);
    }
  });
}

const server = http.createServer(async (req, res) => {
  // 允许前端跨域访问（开发阶段）
  res.setHeader('Access-Control-Allow-Origin', '*');
  res.setHeader('Access-Control-Allow-Methods', 'GET, POST, OPTIONS');
  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');

  const url = new URL(req.url, `http://localhost:${PORT}`);

  if (req.method === 'OPTIONS') {
    res.writeHead(204);
    res.end();
    return;
  }

  if (url.pathname === '/api/search' && req.method === 'POST') {
    let body = '';
    req.on('data', (chunk) => (body += chunk));
    req.on('end', async () => {
      try {
        const { query, topK = 5 } = JSON.parse(body);
        const results = await search(query, Number(topK));
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ query, results }));
      } catch (e) {
        res.writeHead(500, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ error: e.message }));
      }
    });
    return;
  }

  if (url.pathname === '/' || url.pathname === '/index.html') {
    serveStatic(res, path.join(__dirname, 'index.html'), 'text/html');
    return;
  }

  res.writeHead(404);
  res.end('Not found');
});

(async () => {
  if (!process.env.OPENAI_API_KEY) {
    console.error('错误：请设置 OPENAI_API_KEY 环境变量');
    process.exit(1);
  }
  await buildIndex();
  server.listen(PORT, () => {
    console.log(`组件库 RAG 搜索服务已启动：http://localhost:${PORT}`);
  });
})();
```
