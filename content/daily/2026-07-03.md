## 今日主题（1 分钟阅读）

AI 应用正在从「输入框 + 文本回答」快速进化到「随手拍、随口说、随时问」。
对前端来说，真正的挑战不是调用某个 API，而是如何在前端把 **文本、图像、语音** 三类异构输入统一成可维护、可扩展、可降级的消息协议，并在 UX 上做到自然流畅。

今天的主题是：**多模态前端的消息抽象与采集层设计**。

---

## 核心概念（5 分钟精读）

### 1. 用 Message Parts 统一多模态消息

不管是 OpenAI 的 `content: [{type: 'text'}, {type: 'image_url'}]`，还是 Anthropic 的 `content` block，本质都在做同一件事：把一条消息拆成若干 **Part**，每个 Part 有类型和载荷。

前端应该尽早建立自己的抽象，而不是把 OpenAI/Claude 的 schema 直接透传到组件里：

```ts
type Part =
  | { type: 'text'; text: string }
  | { type: 'image_url'; image_url: { url: string } }
  | { type: 'audio_url'; audio_url: { url: string } }
  // 未来可扩展：video、file、sensor 等

interface Message {
  role: 'user' | 'assistant' | 'system'
  content: Part[]
}
```

这样做的好处：
- UI 层只关心 `Part[]`，不关心后端是哪家模型。
- 切换模型时，只需要写一层 adapter 把内部协议转成目标 API schema。
- 未来加新模态时，UI 组件可以按需扩展，而不是重写消息流。

### 2. 前端分层职责

一个可维护的多模态采集系统，建议分成四层：

| 层级 | 职责 | 典型技术 |
|------|------|----------|
| 采集层 | 拿到原始媒体：麦克风、摄像头、文件选择、剪贴板 | `getUserMedia`、`<input type="file">`、Clipboard API |
| 压缩层 | 降低分辨率、转码、转文字，减少 token 与带宽 | Canvas、Web Speech API、MediaRecorder |
| 协议层 | 把处理后的媒体包装成 `Part[]` | 内部 Message schema + adapter |
| 渲染层 | 预览、流式输出、错误回退 | React/Vue、ReadableStream、Suspense/ErrorBoundary |

**关键认知**：前端不是只负责「把文件传上去」。在 AI 场景下，前端是第一个控制成本和质量的地方。

### 3. Token 预算与降级策略

图像和语音都是「烧钱大户」。高级前端应该在前端做前置控制：

- **图像**：上传前先 Canvas 压缩到模型建议尺寸（如 OpenAI GPT-4o 推荐 512~1024px 短边）。
- **语音**：优先本地 Speech-to-Text（Web Speech API）转文本后上传，只有必须保留语气时才上传音频。
- **备选**：当模型不支持某种模态时，自动降级为文字描述或提示用户。

### 4. UX 模式：渐进式采集 + 流式反馈

多模态交互最怕「点了发送后黑屏等结果」。建议的 UX：
- 实时预览已采集的 Parts。
- 发送后先本地显示用户消息，再开启流式回复。
- 对长语音、大图给出压缩/转码进度。
- AI 输出异常时，提供「重试」「移除图片再试」「仅发送文字」的降级入口。

## 代码实践（15 分钟）

下面是一个可直接运行的单文件 Demo，演示如何把**文本输入 + 图片上传 + 语音录入**统一成一条多模态消息，并模拟流式回复。

**使用方法**：把代码保存为 `multimodal-demo.html`，用 Chrome 直接打开即可体验。

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>多模态输入组件 Demo</title>
  <style>
    body {
      font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
      max-width: 720px;
      margin: 40px auto;
      padding: 0 16px;
      line-height: 1.6;
    }
    textarea {
      width: 100%;
      height: 80px;
      padding: 10px;
      box-sizing: border-box;
      border-radius: 8px;
      border: 1px solid #ccc;
    }
    .row {
      display: flex;
      gap: 12px;
      margin: 12px 0;
      align-items: center;
      flex-wrap: wrap;
    }
    button {
      padding: 8px 16px;

      background: #fff;
      cursor: pointer;
    }
    button.recording {
      background: #ff4d4f;
      color: #fff;
      border-color: #ff4d4f;
    }
    button:disabled {
      opacity: 0.5;
      cursor: not-allowed;
    }
    #preview {
      display: flex;
      gap: 8px;
      flex-wrap: wrap;
      margin: 12px 0;
    }
    .part-chip {
      background: #f0f0f0;
      padding: 6px 10px;

      font-size: 13px;
      display: flex;
      align-items: center;

    }
    .part-chip img {
      width: 32px;

      object-fit: cover;

    }

      background: #f6f8fa;
      padding: 12px;
      border-radius: 8px;
      overflow-x: auto;
      font-size: 12px;
    }
    #reply {
      min-height: 40px;
      padding: 12px;
      border-left: 3px solid #1890ff;
      background: #e6f7ff;
      border-radius: 0 8px 8px 0;
      white-space: pre-wrap;
    }
  </style>
</head>
<body>
  <h1>多模态输入组件原型</h1>

  <textarea id="textInput" placeholder="输入问题，或留空直接发送图片/语音..."></textarea>

  <div class="row">
    <input type="file" id="imageInput" accept="image/*" />
    <button id="recordBtn">🎙️ 按住说话</button>
    <button id="sendBtn">发送多模态消息</button>
  </div>

  <div id="preview"></div>
  <h3>最终发送给 LLM 的 payload（已规范化）：</h3>
  <pre id="payload"></pre>

  <h3>模拟 AI 流式回复：</h3>
  <div id="reply"></div>

  <script>
    // 内部多模态消息抽象
    const parts = [] // { type, ... }

    const textInput = document.getElementById('textInput')
    const imageInput = document.getElementById('imageInput')
    const recordBtn = document.getElementById('recordBtn')
    const sendBtn = document.getElementById('sendBtn')
    const preview = document.getElementById('preview')
    const payloadEl = document.getElementById('payload')
    const replyEl = document.getElementById('reply')

    // 1. 图片处理：先压缩再转 base64，控制 token 与上传大小
    imageInput.addEventListener('change', async (e) => {
      const file = e.target.files[0]
      if (!file) return
      const dataUrl = await resizeImageToDataURL(file, 512)
      parts.push({ type: 'image_url', image_url: { url: dataUrl } })
      renderPreview()
      imageInput.value = '' // 允许重复选择同一张图
    })

    function resizeImageToDataURL(file, maxShortSide) {
      return new Promise((resolve, reject) => {
        const img = new Image()
        img.onload = () => {
          const canvas = document.createElement('canvas')
          const ctx = canvas.getContext('2d')
          const ratio = Math.min(maxShortSide / img.width, maxShortSide / img.height, 1)
          canvas.width = img.width * ratio
          canvas.height = img.height * ratio
          ctx.drawImage(img, 0, 0, canvas.width, canvas.height)
          // quality 0.85 是兼顾清晰度与体积的常用平衡点
          resolve(canvas.toDataURL('image/jpeg', 0.85))
        }
        img.onerror = reject
        img.src = URL.createObjectURL(file)
      })
    }

    // 2. 语音处理：使用 Web Speech API 本地转文字，只把文本加入消息
    // 注意：生产环境如需保留原声，应改用 MediaRecorder + 服务端 ASR
    let recognition = null
    if ('webkitSpeechRecognition' in window || 'SpeechRecognition' in window) {
      const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition
      recognition = new SpeechRecognition()
      recognition.lang = 'zh-CN'
      recognition.continuous = false
      recognition.interimResults = false

      recognition.onresult = (event) => {
        const transcript = event.results[0][0].transcript
        if (transcript.trim()) {
          parts.push({ type: 'text', text: `🎤 ${transcript}` })
          renderPreview()
        }
      }

      recognition.onerror = (e) => {
        console.error('语音识别错误', e)
        alert('语音识别失败，建议检查麦克风权限或浏览器支持')
      }
    }

    recordBtn.addEventListener('mousedown', () => {
      if (!recognition) {
        alert('当前浏览器不支持 Web Speech API，请使用 Chrome 或 Edge')
        return
      }
      recordBtn.classList.add('recording')
      recordBtn.textContent = '🔴 录音中...'
      recognition.start()
    })

    recordBtn.addEventListener('mouseup', () => {
      if (!recognition) return
      recordBtn.classList.remove('recording')
      recordBtn.textContent = '🎙️ 按住说话'
      recognition.stop()
    })

    // 3. 渲染已采集的多模态 Parts
    function renderPreview() {
      preview.innerHTML = ''
      parts.forEach((part, idx) => {
        const chip = document.createElement('div')
        chip.className = 'part-chip'
        if (part.type === 'text') {
          chip.textContent = `📝 ${part.text.slice(0, 24)}${part.text.length > 24 ? '...' : ''}`
        } else if (part.type === 'image_url') {
          const img = document.createElement('img')
          img.src = part.image_url.url
          chip.appendChild(img)
          chip.append('🖼️ 图片')
        }
        // 删除按钮
        const del = document.createElement('span')
        del.textContent = '✕'
        del.style.cursor = 'pointer'
        del.style.color = '#999'
        del.onclick = () => {
          parts.splice(idx, 1)
          renderPreview()
        }
        chip.appendChild(del)
        preview.appendChild(chip)
      })
    }

    // 4. 发送：组装 Message，打印 payload，并模拟流式回复
    sendBtn.addEventListener('click', () => {
      const text = textInput.value.trim()
      // 文本框内容也作为一个 Part，放在最前
      const finalParts = text ? [{ type: 'text', text }, ...parts] : [...parts]
      if (finalParts.length === 0) {
        alert('请输入文字、上传图片或录入语音')
        return
      }

      const message = {
        role: 'user',
        content: finalParts
      }

      payloadEl.textContent = JSON.stringify(message, null, 2)

      // 实际项目中，这里把 message 转成 OpenAI / Anthropic / 自研模型的格式发出去
      // 例如：const openAIBody = { model: 'gpt-4o', messages: [message] }

      simulateStreaming('收到一条包含 ' + finalParts.length + ' 个 part 的多模态消息，正在统一处理中...')
    })

    function simulateStreaming(fullText) {
      replyEl.textContent = ''
      let i = 0
      const timer = setInterval(() => {
        replyEl.textContent += fullText[i]
        i++
        if (i >= fullText.length) clearInterval(timer)
      }, 40)
    }
  </script>
</body>
</html>
```

### 代码要点回顾

1. **消息统一**：所有输入最终都变成 `Part[]`，UI 只消费 Parts。
2. **图像压缩**：上传后立即用 Canvas 缩放到短边 512px，避免直接把 4K 原图塞进 LLM。
3. **语音降级**：先用 Web Speech API 本地转文本；保留原声的场景再走服务端 ASR。
4. **可扩展**：要加视频、文件、传感器，只需扩展 `Part` 类型和对应的渲染 Chip。
5. **协议转换**：发送前用一层 adapter 把内部 `Message` 转成目标模型 schema，组件层零改动。

1. **扩展性设计**：如果下季度产品要求支持视频片段和实时传感器数据，你当前的 `Message` 与 `Part` 抽象能否平滑扩展？哪些前端反模式会让这次扩展变成「重写」？
