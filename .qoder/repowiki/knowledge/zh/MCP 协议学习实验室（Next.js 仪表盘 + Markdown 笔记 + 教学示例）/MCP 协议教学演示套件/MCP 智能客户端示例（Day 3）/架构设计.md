单文件脚本 `smart-client.ts` 作为 MCP Client 入口，依赖 `@modelcontextprotocol/sdk` 的 `Client` 与 `StdioClientTransport`，以 `npx tsx` spawn 方式启动位于 `../day2-mcp-server/frontend-helper-server.ts` 的 Server 子进程，并通过 `initialize` 握手建立连接。代码按 MCP Client 四大职责分层组织：`createClient` 负责生命周期（spawn/connect/close），`discoverCapabilities` 调用 `listTools` 获取 Tool 列表及 JSON Schema，`callToolSafe` 封装 `callTool` 并区分业务错误（`isError: true`）与传输层异常，`printDepsAnalysis/printOutdated/printComponentPath` 负责解析 `content[0].text` 中的 JSON 并格式化输出。主流程 `main()` 串联上述步骤，最后调用 `client.close()` 优雅关闭。模块仅依赖 SDK 与 Node 标准库，无额外框架或配置。
