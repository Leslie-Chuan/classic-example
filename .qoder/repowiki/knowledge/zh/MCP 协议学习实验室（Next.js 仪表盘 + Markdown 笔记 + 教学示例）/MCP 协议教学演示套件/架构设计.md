模块按 Day1→Day2→Day3 的教学递进组织为三个独立 npm 子项目，彼此无代码级依赖，仅通过 MCP JSON-RPC over stdio 协议通信：day1-mcp 提供基础文件系统 Server（read_file、list_dir），day2-mcp-server 在其上叠加 zod 运行时校验并扩展出前端辅助 Tool，day3-mcp-client 作为父进程用 StdioClientTransport 拉起 day2 server 子进程完成 initialize → listTools → callTool → close 完整生命周期。顶层 demos/tsconfig.json 共享 ES2022 target、ESNext moduleResolution 与 noEmit 配置，使各 demo 可被 tsx 直接执行；依赖方向严格单向 client → server → 本地文件系统/child_process，确保每个 Demo 可独立运行。
