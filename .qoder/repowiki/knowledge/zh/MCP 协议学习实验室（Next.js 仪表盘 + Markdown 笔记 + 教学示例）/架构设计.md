根目录通过 package.json 的 scripts（dev/build/start/lint）提供单一启动入口；Next.js 应用（app/）作为运行时承载内容渲染与交互，使用 gray-matter 解析 content/ 下按日期组织的 Markdown 笔记并借助 shiki 进行代码高亮展示；demos/ 在 tsconfig.json 中被 exclude 排除出 Next 构建流程，保持为独立的 TypeScript 项目，可单独运行 MCP Server/Client 端到端验证。三者通过“内容即数据”的约定协作：content/ 产出结构化 Markdown，app/ 消费并可视化，demos/ 提供可验证的代码片段，形成“学-练-展”闭环。
