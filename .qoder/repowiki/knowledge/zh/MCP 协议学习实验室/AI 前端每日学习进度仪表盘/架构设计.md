采用 Next.js App Router 的目录路由结构：`src/app/` 下以 `page.tsx` 定义页面（首页仪表盘 `/`、模块列表 `/modules`、动态文章 `/day/[dayNum]`），`layout.tsx` 作为根布局统一注入深色主题、全局导航与 `<main>` 容器；数据层集中在 `src/lib/`，其中 `constants.ts` 声明 MODULES/SKILLS/LEARN_START_DATE/TOTAL_DAYS 等配置，`content.ts` 通过 `fs` + `gray-matter` 在构建期扫描 `content/daily/*.md` 文件生成 `DayContent[]`，并提供 `getStats`、`getCalendarData`、`getDayByNumber` 等纯函数供服务端组件调用，`markdown.ts` 使用 shiki 将代码块高亮并做简易 Markdown→HTML 转换；视图层按职责拆分到 `src/components/`（ProgressCalendar、SkillMatrix、DayCard、DayDemo、MCPPlayground）和 `src/hooks/useMCPTool.ts`（封装 MCP Tool 调用的客户端 Hook）。依赖方向单向：app → components/hooks → lib，lib 不反向引用任何 UI 代码。
