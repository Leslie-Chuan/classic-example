模块包含两个并列的 npm 子项目：`day1-mcp/` 实现一个提供 `read_file`、`list_dir` Tool 与 `fs://codebase-structure` Resource 的文件系统 MCP Server；`day2-mcp-server/` 在此基础上引入 Zod Schema 校验并扩展为三个纯 Tool（`analyze_deps`、`check_outdated`、`suggest_component_path`），以“Transport → Protocol → Handler”三层结构组织代码。每个子项目均由一对镜像脚本构成：server 侧通过 `StdioServerTransport` 暴露能力，client 侧使用 `StdioClientTransport({ command: 'npx', args: ['tsx', serverPath] })` 拉起同一目录下的 server 子进程并以仓库根为 cwd，依次调用 `listTools` → `callTool` → `listResources` → `readResource` 完成端到端验证。依赖方向单向：client → server → 本地文件系统 / child_process。顶层 `demos/tsconfig.json` 提供共享 TS 配置（ES2022 target、ESNext moduleResolution、noEmit）供各 demo 复用。
