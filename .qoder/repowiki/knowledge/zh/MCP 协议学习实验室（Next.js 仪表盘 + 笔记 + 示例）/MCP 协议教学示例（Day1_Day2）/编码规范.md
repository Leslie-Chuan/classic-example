- Server 能力通过 `server.setRequestHandler` 绑定 SDK 提供的 RequestSchema，Tool 走 `CallToolRequestSchema`、Resource 走 `ReadResourceRequestSchema` 两条独立路径处理。
- Tool 参数使用 Zod schema 在 handler 内通过 `.parse(args)` 进行运行时校验，并在 `ListToolsRequestSchema` 中同步声明 JSON Schema 供 Client 展示。
- 对文件系统访问统一先 `path.resolve(ROOT_DIR, ...)` 再校验结果是否以 `ROOT_DIR` 开头，拒绝越界路径以防止路径穿越攻击。
- 每个脚本顶部保留中文注释说明用途与运行命令，便于教学场景快速定位。
- 日志仅输出到 stderr（`console.error`），stdout 被 JSON-RPC 协议独占。
