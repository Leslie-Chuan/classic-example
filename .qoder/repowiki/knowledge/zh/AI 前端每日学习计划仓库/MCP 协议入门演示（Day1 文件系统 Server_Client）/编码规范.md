- Server 能力通过 `server.setRequestHandler` 绑定到 SDK 提供的 RequestSchema，Tool 与 Resource 分别走 `CallToolRequestSchema` 和 `ReadResourceRequestSchema` 两条路径处理。
- Tool 参数使用 JSON Schema 在 `inputSchema` 中声明类型、描述与默认值，便于 MCP 客户端自动生成调用界面。
- 对文件系统访问统一先 `path.resolve(ROOT_DIR, ...)` 再校验结果是否以 `ROOT_DIR` 开头，防止路径穿越攻击。
