模块以 `demos/day1-mcp/` 为独立 npm 子项目，包含一对互为镜像的进程：`file-system-server.ts` 作为 MCP Server，通过 `StdioServerTransport` 暴露两个 Tool（`read_file`、`list_dir`）和一个 Resource（`fs://codebase-structure`），所有请求处理器由 `setRequestHandler` 注册到对应 Schema（`ListToolsRequestSchema`、`CallToolRequestSchema`、`ListResourcesRequestSchema`、`ReadResourceRequestSchema`）；`test-client.ts` 作为 MCP Client，使用 `StdioClientTransport` 以 `npx tsx` 方式拉起同一目录下的 server 进程，并依次调用 `listTools`、`callTool`、`listResources`、`readResource` 完成端到端验证。依赖方向单向：client → server → 本地文件系统（通过 `path.resolve` + 前缀校验限制访问范围）。顶层 `tsconfig.json` 提供共享 TS 配置（ES2022 + ESNext moduleResolution + noEmit），供各 demo 复用。
