模块由一对互为镜像的 TypeScript 脚本组成，基于 @modelcontextprotocol/sdk 实现 MCP 协议通信：
- file-server.ts 作为 MCP Server，仅暴露 read_file / write_file / list_directory / execute_command 四个工具，在 CallToolRequestSchema 中直接调用 node:fs 与 node:child_process，不做任何路径或命令校验，刻意体现“Server 不可信”的安全暗面。
- secure-client.ts 作为 MCP Client Gateway，通过 StdioClientTransport 以子进程方式启动并连接 file-server.ts，在 callTool 前后嵌入四层拦截：Discovery（listTools 后按规则对工具打 low/medium/high 标签）、Execution（PermissionEngine 基于 toolPattern + 路径白名单 + 调用次数上限做放行/拒绝/需确认判断）、Audit（每次决策写入 auditLog 并打印摘要）、Transport（stdio 子进程隔离）。
- 依赖方向单向：secure-client.ts → file-server.ts；两者之间仅通过 MCP 标准请求/响应交互，无共享状态。
- 运行时通过 package.json 的 tsx 脚本分别启动 server 与 demo，demo 内再 fork 出 server 进程形成 Client-Gateway-Server 三层结构。
