- 每个 MCP 工具通过 ListToolsRequestSchema 声明 name/description/inputSchema，再由 CallToolRequestSchema 统一分发处理，工具名与实现一一对应。
- 权限策略以配置数组形式集中定义（PERMISSION_RULES），每条规则包含 toolPattern、allowedPaths、requireConfirmation、riskLevel、maxCalls 等字段，由 PermissionEngine.evaluate 顺序匹配执行。
- 所有调用决策（allow/deny/confirm_allow/confirm_deny）统一通过 recordAudit 写入审计日志，并在结束时按工具分组统计输出。
- 高风险操作采用 requireConfirmation 标记，Demo 模式自动放行，生产模式返回需要用户交互的拒绝结果，以此区分演示与真实部署行为。
- 路径校验统一通过 extractPath 提取参数中的路径字段，再用 isPathAllowed 将目标路径与 allowedPaths 进行 resolve 后的前缀匹配，防止路径逃逸。
