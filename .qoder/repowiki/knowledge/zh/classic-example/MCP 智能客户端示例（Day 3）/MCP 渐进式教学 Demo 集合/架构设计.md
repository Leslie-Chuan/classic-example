模块按教学递进组织为四个并列的 TypeScript 子项目（day1-mcp、day2-mcp-server、day3-mcp-client、day5-security），彼此无代码级依赖，仅通过 MCP JSON-RPC over stdio 通信：day1 提供基础文件系统 Server，day2 叠加 zod 运行时校验并扩展前端辅助 Tool，day3 作为父进程用 StdioClientTransport 拉起 day2 server 子进程完成完整生命周期，day5 引入带路径白名单与风险分级的 Secure Gateway Client 演示安全模型；顶层 demos/tsconfig.json 共享 ES2022 target、ESNext moduleResolution 与 noEmit 配置使各 demo 可被 tsx 直接执行，依赖方向严格单向 client → server → 本地文件系统/child_process，确保每个 Demo 可独立运行。
