- 每个 MCP Client 职责用独立 async 函数封装（`createClient`/`discoverCapabilities`/`callToolSafe`/`print*`），由 `main()` 顺序编排。
- 工具调用统一通过 `callToolSafe` 包装，区分 `result.isError` 业务错误与 try/catch 捕获的传输层异常两类错误路径。
- Server 路径与项目根路径通过 `path.resolve(import.meta.dirname, ...)` 相对定位，避免硬编码绝对路径。
- 对外部返回的 `content[]` 统一以 `JSON.parse((result.content as any[])[0].text)` 解析后再交由专用打印函数处理。
