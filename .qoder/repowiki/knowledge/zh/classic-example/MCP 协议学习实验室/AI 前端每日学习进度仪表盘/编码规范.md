- 页面组件使用 Next.js App Router 的服务端组件模式，通过 `generateStaticParams` 预生成 `/day/[dayNum]` 的所有静态路由参数。
- 数据读取统一集中在 `src/lib/content.ts` 中，页面仅调用 `getAllDays`、`getStats`、`getCalendarData` 等纯函数，避免在组件内直接操作文件系统。
- Markdown 内容通过 `gray-matter` 解析后以 `rawContent` 原始文本与 `content` 渲染后的 HTML 双份保存，由 `renderMarkdown` 在服务端渲染并注入 `dangerouslySetInnerHTML`。
- 模块、技能、学习周期等元数据以 TypeScript 接口 + 常量数组形式集中声明于 `constants.ts`，UI 层通过遍历这些常量渲染，而非硬编码字符串。
- 客户端交互逻辑封装为 React Hooks（如 `useMCPTool`），统一暴露 `{ data, loading, error, execute }` 状态结构，并通过 AbortController 实现超时控制。
