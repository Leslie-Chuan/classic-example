# AI 前端每日学习

高级前端开发者 AI 时代学习计划 — 代码实验室 + 知识库 + 进度追踪。

## 技术栈

- **Next.js 16** (App Router) + **TypeScript** + **Tailwind CSS v4**
- **Shiki** 代码语法高亮
- 自定义 Markdown 渲染引擎

## 功能

- 学习仪表盘：打卡日历、进度统计、技能成长矩阵
- 每日学习页：Markdown 内容渲染 + 代码高亮
- 模块浏览：5 大模块分类导航

## 开发

```bash
npm install
npm run dev
```

访问 [http://localhost:3000](http://localhost:3000)
